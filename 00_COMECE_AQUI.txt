🎓 COMO FUNCIONA
──────────────────────────────────────────────────────────────────────────────

Seus arquivos foram salvos em UTF-16 LE em vez de UTF-8.
Vite não consegue ler UTF-16 LE.

Solução:

  1. Plugin detecta: "Este arquivo é UTF-16 LE"
  2. Plugin converte: UTF-16 LE → UTF-8
  3. Plugin remove: BOM (Byte Order Mark)
  4. Arquivo é salvo: UTF-8 puro ✓
  5. Build executa: Sem problemas ✓

Tudo 100% automático!
